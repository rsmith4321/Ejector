# Store 1.0 (6): explain both permission models

Help and Settings include an optional App Store & website versions disclosure. Both editions have the same features. The Store edition uses per-card sandbox authorization for folder detection and cleaning, and formatting can invalidate access. The website edition relies on macOS drive-access permissions without Easy Eject per-card authorization. Neither requires folder authorization for plain eject, and both use volume identity for optional import profiles.

The comparison link opens https://easyeject.com/editions/ in the browser. There is no download/installer/updater inside the Store app; it keeps Mac App Store updates and sandbox entitlements. Shared engines and safety defaults are unchanged.
