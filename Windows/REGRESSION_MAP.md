## Remaining evidence and audit work

Close every **Partial** row with the exact combination/variant and inspect the relevant assertions. Then inventory the other named Mac harnesses: defaults, completion/eject/notification, bulk/grouped removal, manual Quick Share/EasyShare and update safety. No suite is considered equivalent merely because its total test count is high. Preserve platform-specific differences explicitly rather than silently omitting an applicable behavior.

The new missing-folder implementation keeps the readable source and all existing selected ancestors held and compares canonical paths/native directory identities before reads. Empty directories can still be renamed on Windows despite their held attribute handles; the replacement fixture demonstrated this and the implementation now refuses it. Other long-lived path owners should be audited for the same assumption, using existing file leases/canonical checks as evidence rather than assuming directory handles guarantee immobility.

Real encoder/probe/full-decoder and official LUT proof, foreground/DPI/clipboard/tray/login/hotkey/notification/wake checks, Ryan-identified disposable camera/card/reader/destination tests and trusted signing/direct-download validation remain outside these fixture results. Nothing in this mapping grants real-device operation or publishing authority.
