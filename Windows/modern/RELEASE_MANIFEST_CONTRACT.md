# Modern release envelope and runtime inventory

This is one source milestone toward the full modern package policy. It does not enable a channel, approve a publisher, inspect/extract a package, launch code, install components or establish release trust. `ModernProductionChannel` remains null. Classic release schema/package/channel behavior and its 64 KiB authenticated-manifest bound remain unchanged.

The modern local review folder has 600 files, including .NET and Windows App SDK components and localized assets. A complete path/size/hash inventory exceeds the classic manifest bound. `ModernWindowsReleaseManifest` therefore parses a small **authenticated envelope** whose exact SHA-256/length binds a separate `windows-modern-files.json` inventory. The inventory is not independently trusted; it is admitted only through that binding. The existing detached CMS/native publisher verification produces the immutable envelope snapshot. Positive test chain trust is faked; no production signer is configured or inferred from an inspected file.

Envelope schema 2 requires exactly `format`, `application` (`EasyEject.Modern`), `platform` (`windows-x64`), canonical four-part stable `version`, lowercase 40-digit `sourceRevision`, `runtime` and `fileIndex`. Runtime fields are `dotnet` (canonical three-part .NET 10 family), `windowsAppSdk` (canonical three-part version 2 family) and `minimumWindows` (`10.0.19041.0`, the current project's compiled minimum). These declarations are metadata, not proof of the actual DLL/dependency/runtime configuration. Windows 11 remains the requested supported acceptance target.

`fileIndex` requires its exact constant name, byte `length`, lowercase SHA-256, file `count` and `totalLength`. Index schema 1 requires exactly `format` and `files`; each file has `path`, positive `length` and lowercase SHA-256. Inventory bytes are frozen before parsing, bounded at 512 KiB/2048 files, with a 1 GiB single-file and 2 GiB aggregate limit. Strict UTF-8 without BOM, complete JSON grammar, field/type uniqueness, nesting/string bounds and canonical integer/version forms are required. The ordered inventory is immutable after parsing. These bounds cover the current 269 MiB local folder; they are not approval of that unsigned folder as a release.

Paths use forward slashes, bounded ASCII components, supported observed payload extensions, strict ordinal inventory ordering and case-insensitive collision checks. Absolute/drive/ADS paths, traversal, empty components, backslashes, trailing dots/spaces, reserved Windows device names, unsupported extensions, release-metadata names and file/directory prefix collisions refuse. Required exact entries include the modern apphost/managed app/deps/runtimeconfig, shared runtime, CLR/host/native Windows App SDK/WinForms components, Easy Eject artwork and release README/LICENSE. This does not prove complete third-party license compliance or that DLLs are genuine, signed, compatible or sufficient for startup.
