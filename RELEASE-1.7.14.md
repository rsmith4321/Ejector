# Easy Eject 1.7.14

- Large imports no longer use more and more memory as they run. Memory stays low for the whole import.
- Clean & Eject now works on Mac-formatted drives. Protected macOS system folders are skipped and left untouched.
- Plugging in a card no longer re-checks every other connected drive.
- New, optional AirDrop Inbox: move files you AirDrop to this Mac from Downloads into a folder you choose, and convert HEIC photos to JPEG. It stays off until you turn it on in Settings.
- Quick Share preview: make 1080p or 4K sharing copies from a completed Insta360 Luna or DJI O4 Pro import, with the manufacturer's LUT if you want it. It is off by default and needs FFmpeg installed on your Mac.
- The menu bar warning now has a View Issue item that explains the problem, and it clears once the cards are unplugged.
- Imports continue when macOS needs to renew permission for the destination folder, and removing a device profile asks first.
- Safer removal of originals and hidden-file cleaning if a card changes during the operation.

Requires macOS 14 or later. Universal build for Apple silicon and Intel. This is the Website edition; the sandboxed App Store edition receives updates through Apple.
