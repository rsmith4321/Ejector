# Easy Eject 1.7.0

- Set defaults for new devices: media selection, camera previews, clean folder layout, automatic import, and the eject prompt. Each new profile starts with these choices and remains independently editable. Existing profiles keep their settings. Original deletion and Trash recovery require per-device choices.
- The website edition automatically checks for signed updates on GitHub. You choose whether and when to install. Turn automatic checking off in Settings if preferred. Updates wait for active work and open dialogs before restarting.
- Import completion uses a compact native eject dialog with Keep Connected as the default. Cameras exposing multiple mounted storage sources show an explicit grouped eject choice. The device-import window scrolls as one area.

The Store edition uses Apple's updater. These changes do not replace the Store build already submitted for review. Website 1.6.2 and earlier need one manual download to acquire the new updater.
